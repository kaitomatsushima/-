# うちの冷蔵庫

## 概要

「うちの冷蔵庫」は、冷蔵庫にある食材の消費期限を管理するCLIアプリです。

一人暮らしなどで食材の管理が面倒な人でも、簡単に食材を登録・確認・更新・削除できるようにすることを目的としています。

## 開発背景

食材を購入したものの、消費期限を忘れてしまい、期限切れになってしまうことがあります。

そこで、冷蔵庫にある食材と消費期限を簡単に管理できるアプリを作成しました。

## 主な機能

- 食材の登録
- 食材一覧の表示
- 食材情報の更新
- 食材の削除
- 消費期限の管理
- 消費期限が近い順での表示
- カテゴリーによる食材管理

## カテゴリー

以下のカテゴリーから食材を登録できます。

- 肉
- 魚
- 野菜
- 乳製品
- その他

「肉」「魚」「野菜」「乳製品」は、カテゴリーに応じて消費期限を自動で設定します。

「その他」の場合は、カテゴリー名と消費期限を自分で入力します。
