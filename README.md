# うちの冷蔵庫

## アプリ概要

食材の登録・一覧表示・更新・削除を行い、冷蔵庫にある食材の消費期限を管理するCLIアプリケーションです。

食材をカテゴリーごとに管理し、消費期限の近い食材から確認できるようにすることで、食材の期限切れを防ぐことを目的としています。

## 主な機能

- 食材機能
  - 食材の登録
  - 食材一覧表示
  - 食材情報の更新
  - 食材の削除
- カテゴリー機能
  - 食材カテゴリーの選択
  - カテゴリーに応じた消費期限の自動設定
  - 「その他」カテゴリーの登録
- 消費期限管理
  - 消費期限の管理
  - 消費期限の近い順での一覧表示

## クラス構成・役割

### fridge package

- Main
  - アプリ全体の進行やメニューを制御
  - 各クラスのメソッドを呼び出す

- Fridge
  - 冷蔵庫に登録されている食材を管理
  - 食材の登録・表示・更新・削除を行う
  - 消費期限の近い順に食材を表示

- FoodItem
  - 1つの食材情報を保持
  - 食材ID・食材名・カテゴリー・登録日・消費期限などを管理

- Category
  - 食材カテゴリーを管理
  - 肉・魚・野菜・乳製品・その他を定義
  - カテゴリーごとの消費期限を管理

- Input
  - ユーザーからの入力を処理
  - 食材名・ID・日付などの入力を受け付ける
  - 入力値のチェックを行う

## データ設計

### データを表すクラス

- FoodItem
  - 食材ID
  - 食材名
  - カテゴリー
  - 登録日
  - 消費期限

- Category
  - カテゴリー名
  - カテゴリーごとの標準消費期限

### データをまとめて管理するクラス

- Fridge
  - `ArrayList<FoodItem>`として食材一覧を保持
  - 食材の登録・取得・更新・削除を行う

## カテゴリーと消費期限

以下のカテゴリーを用意しています。

| カテゴリー | 消費期限 |
| --- | --- |
| 肉 | 登録時に自動設定 |
| 魚 | 登録時に自動設定 |
| 野菜 | 登録時に自動設定 |
| 乳製品 | 登録時に自動設定 |
| その他 | ユーザーが入力 |

「肉」「魚」「野菜」「乳製品」は、カテゴリーに設定された標準日数をもとに消費期限を自動で設定します。

「その他」の場合は、ユーザーがカテゴリー名と消費期限を入力します。

## 実行方法

### 必要な環境

- Java 17
- Eclipse

### Eclipseでの実行

1. このリポジトリをクローンまたはダウンロードする
2. Eclipseを起動する
3. `File`から`Import`を選択する
4. `General`の`Existing Projects into Workspace`を選択する
5. ダウンロードしたプロジェクトの`MyFridge`フォルダを指定する
6. `src/fridge/Main.java`を開く
7. `Run As`から`Java Application`を選択する
